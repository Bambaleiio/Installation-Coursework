# LLMHandler

Содержит .tox файл.
Модуль позволяет вводить фразы/слова и преобразовать их в эмоцию. Есть несколько вариантов для запуска LLM: [Local LLM](#local-llm), [Server LLM](#server-llm), [Internet LLM](#internet-llm)

# Предварительно


Сама установка модуля **требовательна к версиям програмного обеспечивания**

> Предритальная установка

-  Версия Python ([скачать](https://www.python.org/ftp/python/3.11.1/))

```
Python 3.11.1
```

-  Версия TouchDesigner ([скачать](https://derivative.ca/download/archive))

```
64-bit Build 2023.12120
```

- Тип: On/Off

On: Автоматически обрабатывает [Input](#input) при его изменении
Off: Автоматически НЕ обрабатывает [Input](#input) при его изменении

# Variants of LLM

Есть несколько варинтов, как запускать LLM. Каждый из них отличается способом запуска.

## Общие параметры

### Активация

Каждый вариант должен быть включен соотвествующем Pulse параметром в нужной вкладе.

### Библиотеки

Перед использованием того или иного варианта нужно установаить нужные библиотеки. Иначе undefined behavior

---

## Local LLM

Работает локально в проэкте.

---

## Server LLM

Запускается через внешний файл, где работает LLM. Обмен информацией происходит через socket.
Полезен в тех случаях, когда есть своя работающая LLM и нужно посто подключить к модулю.
В качестве шаблома можно использовать встроенный [_server.py](./scripts/_server.py)

---

### Start Server

Запустить сервер через консоль.

### Connect to server

Подключиться к серверу

---

### Network Adress & Port

Реквизиты, по которым происходит подключение.

### Server File

Исполняемый файл сервера

---


### Connected

Подключени ли к серверу или нет

### Server Launched

Запущен ли сервер или нет

### Note

Если завершить процесс с сервером самостоятельно, то поведение параметров [Connected](#connected), [Server Launched](#server-launched) - undefined behavior

---

## Internet LLM

Лучший вариант, если не хочется что-то скачивать или возиться с LLM.
Трепует выход в интернет.

### Параметры

#### LLM Base

Базовая модель, на которой будет все обрабатываться.
Пока что доступен только **YandexGPT**

#### Реквизиты

Дальше входные личные параметры для подключения/запуска LLM
Это: Folder ID, Auth

## OUT

### Emote
- Тип: Text DAT

Выводит эмоцию ввиде Text DAT

### Emote_Table
- Тип: Table DAT

Список всех возможных эмоций

- Структура Table

Единственный Column - Индекс 0
Множество Raw - Индекс от 0 до N
