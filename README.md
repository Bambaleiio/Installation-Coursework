# Web Server

TOX компонента, позволяющая создать web-сервер на **localhost**.
В общем случае такая интеграция позволяет управлять инсталляцией через окно браузера.

---

# Особенности

Для использования данного TOX нужно написать [HTML](#про-in-html) страницу.
Автоматическая обработка:
- Отслеживание всех `<input>`, `<button>`, `<select>` элементов
- Отправка данных при любом изменении
- Генерация уникальных имен для элементов без ID

---

# IN

### HTML
- **Тип**: Text DAT
- **Функционал**: Входной HTML-файл, который будет отображаться в браузере
- **Значение по умолчанию**: [Пример HTML](https://example.com/default.html)
- **Комментарии**: Перед использованием рекомендуется прочитать раздел [про HTML](#про-in-html)

---

# OUT

### QR Code
- **Тип**: Movie File In TOP
- **Функционал**: Выводит сгенерированный QR-код, ведущий на подключение к серверу.
- **Формат**: PNG (обновляется автоматически)

### Server Request
- **Тип**: CHOP
- **Функционал**: Выводит значения параметров, полученных с [HTML](#про-in-html) страницы:
  - `slider_value` (float)
  - `button_clicks` (int)
  - `text_input` (string)

# Server

## Options

### Integrated Data Sender
- **Тип**: On/Off
- **Функционал**: Автоматически добавляет скрипт для отслеживания input на HTML-странице и отправки данных в TouchDesigner.
- **Комментарии**: Отслеживаются все теги из [таблицы](#таблица-с-тегами)

## Parameters

### Port
- **Тип**: int
- **Функционал**: Устанавливает порт для работы сервера (по умолчанию: `9980`)

# QR Code

### Create
- **Тип**: Pulse
- **Функционал**: Создает QR code со ссылкой на подключение к странице
- **Комментарии**: QR code создается в папке Temp, установленной в системе

### Auto Update
- **Тип**: On/Off
- **Функционал**: Автоматически генерирует новый QR-код при изменении:
  - Перезапуска сервера
  - Порта сервера

### Download Python Libs
- **Тип**: Pulse
- **Функционал**: Устанавливает нужные библиотеки python для работы

# Про IN HTML

HTML-страница должна быть единым файлом со всеми интегрированными:
- `<script>` (обязательно)
- `<style>`
- Медиа-ресурсами (base64)

**Формат отправки данных**:
```json
POST {url_сервера}/data
Content-Type: application/json
Body: {"input_1": "value", "button_3": 2}
```

## Таблица с тегами

| Тег         | Тип данных | Описание                     |
|-------------|------------|------------------------------|
| `<input>`   | string/int | Текстовые поля, слайдеры     |
| `<button>`  | int        | Счетчик кликов               |
| `<select>`  | string     | Выпадающие списки            |
| `<textarea>`| string     | Многострочный текст          |
| `<checkbox>`| bool       | Чекбоксы (true/false)        |

**Важно**: Для элементов без ID генерируются имена вида `{тег}_{номер}` (например: `input_1`, `button_3`).
