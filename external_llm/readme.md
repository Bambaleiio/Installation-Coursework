Проверено на python 3.13.2

Выбранная LLM-модель - mistralai/Mistral-7B-Instruct-v0.2. Запуск требует ~8gb VRAM.


## Инструкция по запуску:

1. Установить PyTorch, следуя инструкции с официального сайта [(ссылка).](https://pytorch.org/get-started/locally/)

2. Дополнительно поставить accelerate, bitsandbytes, python-dotenv.

3. Зарегистрироваться на huggingface.co и **создать Access Token**

4. Этот токен положить в .env файл в директории скрипта:
```env
HUGGINFACE_TOKEN="PLACE YOUR TOKEN HERE"
```

---

При первом запуске скрипта будет скачана llm модель. Это займет достаточно много времени.
При последующих запусках нужно будет подождать, пока эта модель загрузится.

### Структура:

server.py - основной файл, запускает сервер, принимает сообщения и отправляет их на обработку в llm

llm_functions - реализация работы с llm, прописаны промпты, запуск llm параметры квантизации.

extra,py - дополнительные функции для обработки сторк и парсинга llm-респонсов
